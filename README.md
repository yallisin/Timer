Criei esse espaço onde é possível utilizar um timer, um cronometro e um relogio mundial. Para utiliza-los é simples, primeiro você clica na função que quer utilizar na barra que se localiza abaixo na tela. Logo após isso, para iniciar o cronometro, basta apertar o botão que dará início a contagem, e logo após as opções de pausar e zerar lhe serão oferecidas. No timer, é necessário digitar primeiro o tempo que lhe será necessário, e as mesmas funções ditas anteriormente aparecerão. No relogio mundial, existem opções de horário que aparecerem em um input para você escolher, após a escolha, o horário atual do principal fuso-horário deste país aparecerá na tela. Futuras atualizações virão.
